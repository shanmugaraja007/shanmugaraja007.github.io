Research

MSc dissertation

Monocular Bird's-Eye-View Reconstruction of Off-Road Field Scenarios for Re-Simulation

Can one uncalibrated looking forward camera on a working agricultural machine give you enough to rebuild the field it drove through, well enough to replay in a simulator? The thesis answers that as a systems and minimum sensor feasibility result rather than a new perception algorithm.

  1. Semantic segmentation of each frame into terrain, grass and trees
  2. Vertical class collapse so tall structure stops smearing across the ground plane
  3. Inverse perspective projection into a metric bird's eye view at 0.10 m per pixel
  4. Monocular visual odometry for ego pose, with keyframe selection
  5. Confidence weighted multi view accumulation into one global map
  6. Rectangle decomposition of the map into simulator ready terrain patches and border features

Along the way: a systematic 32 percent scale error traced back to a camera height recorded from the axle rather than the ground, a 6.7 second GPS time offset that inflated apparent trajectory error by an order of magnitude, and a 32 bit latitude field in a J1939 message the documentation described as 31. Most of the accuracy came from calibration and timing discipline, not from the model.

Projects

Monocular BEV reconstruction pipeline

The research pipeline as production code: swappable segmentation backends, depth weighted voting into a global accumulator, motion based keyframe selection, and automatic chaining into terrain patch creation. Runs a full sequence in about 30 minutes on a 4 GB NVIDIA A2000, with FP16 and batching projected to bring that to 5 to 8 minutes.

Interactive scenario editor

A desktop tool so an engineer can fix what the pipeline gets wrong instead of rerunning it. Unified trajectory editing, multi select, drag to reshape terrain patches, and a one click export to the scenario format the simulator consumes.

Trajectory evaluation toolkit

Benchmarking against a public off road dataset with no ROS install anywhere in the loop. Reads bag files directly, decodes NMEA GPS, projects to UTM zone 32N with 0.03 m round trip error, and aligns estimated against ground truth trajectories with Umeyama to report ATE, RPE and scale.

rosbagsUTMUmeyamaevaluation

Monocular visual odometry

Ego motion from one camera: Harris corner detection, Lucas-Kanade optical flow, and a RANSAC planar motion solver tuned for a vehicle constrained to the ground plane. Built to be debuggable, because every scale bug in the wider pipeline surfaced here first.

Georeferenced map export tool

Zero install utility that turns a GPS track into a georeferenced map image, so recorded routes can be laid over reconstructed terrain and checked by eye against satellite imagery.
